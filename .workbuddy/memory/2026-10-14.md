## 1.27a 控制台残留条带 — 已用 CS 底板覆盖修复

- 结论（前序排查）：1.27a 无 WorldHook/UIHook，`ShowInterface(FALSE)` 只藏控件；控制台面板本体（地图皮肤边框+半透明底图+文字）每帧实时绘制在底带（世界视口 GL y=128 以下，1064x593 客户端）。1.26a 靠 nativeUIPhase 吞批次的机制在 1.27a 不可用。
- 修复方案：放弃逆向 1.27a UI 入口，在 Overlay（present 时绘制，必在游戏画完控制台之后）用不透明 CS 风格底板盖住该条带：
  - `FullscreenView` 新增 `ObserveWorldViewport()`（ViewportHook 在 `!originalWorld` 时记录引擎提交的世界视口，其 GL y 偏移=条带高度）与 `ConsoleStrip()`。
  - `Overlay::Draw` 在武器绘制前画底板：`panelTop = height - strip - 6`（6px 上咬合吞掉控制台顶梁，勿多盖世界画面；初版 -24 会吃掉 24px 世界）。状态文字/武器/购买菜单都在其上层。
  - 1.26a 安全：`consoleStrip` 仅在 `!originalWorld`（1.27a）时被赋值，1.26a 恒为 0 不画底板。
- 实测（bandtest.ps1 + bandcheck.py，build 无警告，ERROR lines=0）：
  - DotA 6.77b：FPS 底带为干净深色面板，状态文字正常；F6 往返（C-fps-again）不复发。
  - 真三 V3.7d（木纹皮肤）：面板左区 sd=0.00（完全均匀）；RTS 视图控制台完好无回归。
- 新测试脚本：`.local/bandtest.ps1`（启动→F6→A-fps/B-rts/C-fps-again 截图+记录 clientOrigin/clientSize 到 `*-geom.txt`）、`.local/bandcheck.py`（按客户区坐标逐行统计条带）。注意截图含窗口边框，必须用 geom.txt 换算客户区坐标，桌面内容会从边框漏进来（真三截图底缘"文字"其实是桌面任务栏）。
